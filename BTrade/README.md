# MA Cross Bot

Торговый бот с ОДНИМ индикатором — **пересечение скользящих средних**
MA(7)/MA(25) (`strategies/ma_cross.py`). Никаких стаканов, ленты сделок,
комитетов фактов, зон и ИИ: решение принимается только по свечам 30m и 3m.

## Логика

1. **Вселенная** — все активные USDT-рынки Binance, стейблкоины исключены,
   остаются только монеты с волатильностью **от 10% за 24 часа**
   (`|24h change|`, настраивается `MIN_24H_VOLATILITY`).
2. **Вход**:
   - сначала находим **пересечение MA(7)/MA(25) на 30m** (символ «вооружается»);
   - входим на **первом** пересечении на **3m** в ту же сторону, что и 30m;
   - рукав снимается, когда закрылась новая 30m-свеча без пересечения (или по
     таймауту `MA_CROSS_ARM_TIMEOUT_SEC`).
   - Сигналы считаются только по ЗАКРЫТЫМ свечам — без репейнта.
   - **Фильтры входа** (`MA_CROSS_FILTERS=1`, по анализу истории WIN vs LOSS):
     анти-чейз (2h-движение в сторону входа ≤ `MA_CROSS_MAX_2H_MOVE`%),
     ATR(3m) ≤ `MA_CROSS_MAX_ATR3_PCT`%, объём ≤ `MA_CROSS_MAX_VOL_RATIO`x,
     лонг не выше `MA_CROSS_MAX_RANGE_POS_LONG`% 24h-диапазона,
     лонг только при 24h ≥ −`MA_CROSS_MAX_24H_MOVE`% (шорт зеркально).
3. **Стоп-лосс** — `ENTRY_SL_ATR_MULT` × ATR(3m), минимум
   `ENTRY_SL_MIN_PCT`% от цены.
4. **Выход — ТОЛЬКО трейлинг-стоп или стоп-лосс.** Тейк-профит, выходы по
   стакану/ленте/индикатору полностью убраны. Трейлинг: безубыток на
   `TRAIL_BREAK_EVEN_R` R, трейл с `TRAIL_START_R` R дистанцией
   `TRAIL_DISTANCE_R` R.
5. **Разворот (`REVERSAL_ENABLED=1`)** — если позицию выбило по НАЧАЛЬНОМУ
   стоп-лоссу (стоп не был подтянут трейлингом) и во время открытой позиции
   3m-индикатор пересёк в противоположную сторону (лонг + 3m вниз → моментальный
   шорт, зеркально для шорта), либо EMAs почти пересеклись
   (`MA_CROSS_REVERSAL_CLOSE_GAP_PCT`%) и цена уже против позиции. SL разворота —
   та же дистанция, что у закрытой позиции; кулдаун повторного входа не
   блокирует разворот.
6. **Расписание (`SCHEDULE_ENABLED=1`)** — работа с `SCHEDULE_WAKE` (09:00) до
   `SCHEDULE_SLEEP` (20:30) по `SCHEDULE_ZONE` (Europe/Kyiv); в 20:30 при
   `SCHEDULE_CLOSE_POSITIONS=1` все позиции закрываются по рынку, до 09:00
   входы не ищутся.
7. **Риск** — риск на сделку, дневной лимит убытка, лимит позиций
   (`MAX_POSITIONS=1`), защитные стоп-ордера на бирже (только SL).
8. **Journal** — SQLite `db/trades.db`: сделки, сигналы, исходы.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

Перед реальной торговлей обязательно `PAPER_TRADING=1`.

## Настройки `.env`

- Индикатор: `MA_CROSS_FAST=7`, `MA_CROSS_SLOW=25`, `MA_CROSS_HTF=30m`,
  `MA_CROSS_LTF=3m`, `MA_CROSS_ARM_TIMEOUT_SEC`.
- Стоп: `ENTRY_SL_ATR_MULT`, `ENTRY_SL_MIN_PCT`.
- Выход: `TRAIL_ENABLED`, `TRAIL_BREAK_EVEN_R`, `TRAIL_START_R`,
  `TRAIL_DISTANCE_R`.
- Разворот: `REVERSAL_ENABLED` (см. п. 5 выше).
- Вселенная: `SCAN_ALL_SYMBOLS`, `MIN_24H_VOLATILITY=10`, `SCAN_TOP_N`,
  `SCAN_POOL_WORKERS`.
- Биржа/риск: `EXCHANGE`, `PAPER_TRADING`, `FUTURES`, `MAX_LEVERAGE`,
  `RISK_*` (см. `core/config.py`), `EQUITY`.

Все ключи задаются только через `.env`.

## Безопасность

- Ключи, засвеченные в сообщениях или логах, немедленно отозвать.
- Для реального Binance: сначала paper, IP whitelist без права вывода средств.
- Бот не гарантирует прибыль; риск — ответственность владельца счёта.
